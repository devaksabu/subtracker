# SubTracker Flutter & Android Home Widget App

This is a complete Flutter project configured with a native Android Home Screen App Widget for tracking mobile recharges and subscriptions.

### Quick Build Steps:

1. Extract this zip.
2. Open terminal in the project root:
   ```bash
   flutter pub get
   flutter build apk --release
   ```
3. Your installable APK will be generated at:
   `build/app/outputs/flutter-apk/app-release.apk`
4. Transfer and install on your Android device.
5. Long-press your home screen -> **Widgets** -> drag **SubTracker** to your screen.
